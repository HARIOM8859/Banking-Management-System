# Banking Management System (Java)

A console-based Banking Management System built using Core Java to practice Object-Oriented Programming, Arrays of Objects, Custom Exception Handling, and Banking Operations.

## Features

### Account Management

* Create Account
* View Account Details
* Search Account
* Delete Account

### Banking Operations

* Deposit Money
* Withdraw Money
* Transfer Money Between Accounts

### Exception Handling

* Account Not Found Exception
* Invalid PIN Exception
* Insufficient Balance Exception
* Invalid Amount Exception

## Technologies Used

* Java
* IntelliJ IDEA
* Git & GitHub

## Concepts Practiced

* Classes and Objects
* Constructors
* Arrays of Objects
* CRUD Operations
* Searching Algorithms
* Object References
* Method Calls
* Custom Exceptions
* Exception Propagation (`throws`)
* Exception Handling (`try-catch`)
